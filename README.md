# Axo SecretShop: как добавлять работы в витрину

Положите файлы в папку `works/` в репозитории и сделайте commit. Vercel сам пересоберёт сайт и заполнит рамки.

| Вкладка | Рамок | Как назвать файл |
|---|---|---|
| Наборы стикеров, «Детализированные» (открывается первой) | 3 | `tgs1s(Название).tgs`, `tgs2s(...)`, `tgs3s(...)` |
| Наборы стикеров, «Упрощённые» | 3 | `tgs1l(Название).tgs`, `tgs2l(...)`, `tgs3l(...)` |
| Наборы стикеров, «Статичные» | 5 | `png1(Название).png` ... `png5(...)` (png, webp, jpg, gif) |
| Наборы эмодзи, «Полностью кастомные» | 3 | `tgs1e(Название).tgs`, `tgs2e(...)`, `tgs3e(...)` |
| Наборы эмодзи, «Кастомные (на шаблоне)» | 1 | `tgs1ec(Название).tgs` |
| Наборы эмодзи, «Шаблонные» | 3 | `tgs1el(Название).tgs`, `tgs2el(...)`, `tgs3el(...)` |
| Аватары | 5 | `avatar1(Название).png` ... `avatar5(...)` (png, jpg, webp, gif, mp4, webm) |

- Номер выбирает рамку: файл с номером 2 встанет во вторую рамку. Пустые рамки показываются как «Скоро добавим».
- Название в скобках показывается под карточкой. Скобки и название можно не писать: `tgs1s.tgs` тоже работает. Вместо пробелов можно `_`.
- Аватары №1 и №2 подписываются «для канала или чата», №3 и дальше «аватарка профиля».
- После типа (`s`, `l`, `e`, `ec`, `el`) обязательно должна идти скобка, точка, пробел, `_` или дефис. Имя `tgs1eLion.tgs` сайт не распознает, пишите `tgs1e(Lion).tgs`.
- Если номер больше числа рамок, например `tgs4s`, карточка добавится в конец.
- Картинки лучше сжимать: до 1000 px по большей стороне и до 500 КБ. Тяжёлые файлы (больше 1,5 МБ) во время сборки попадут в журнал Vercel с пометкой «ТЯЖЁЛЫЙ ФАЙЛ». На телефонах они грузятся долго или не показываются.
- Если заливаете файлы без Git (перетаскиванием), один раз выполните `node scripts/gen-works.js` и загрузите получившийся `works.json`.

## Если что-то не отображается на телефоне

Откройте сайт с `?debug` в конце адреса, например `https://ваш-сайт.vercel.app/?debug`. Внизу экрана появится журнал: сколько файлов найдено и какие не загрузились. Скриншот журнала поможет быстро найти причину.

## Если анимация TGS подтормаживает

Попробуйте открыть сайт с `?r=canvas` в конце адреса. Это другой способ отрисовки, на некоторых телефонах он плавнее. Если так лучше, напишите, и сделаем его основным.

В настройках проекта на Vercel ничего менять не нужно: `vercel.json` уже содержит команду сборки.
